# OpenCV Image Processing Project

## Project Description
This project demonstrates various image processing and computer vision operations using Python and OpenCV. It includes image editing, color detection, resizing, cropping, drawing shapes, watermark creation, and other image manipulation techniques.

## Features
1. Passport Size Photo Generator
2. Image Color Inspector
3. Profile Picture Editor
4. Before & After Image Visualization
5. Dominant Color Extraction using HSV
6. Watermark Designer
7. Face Highlighter
8. Drawing Shapes Poster
9. Sports Ground Sketch
10. Greeting Card Creator

## Technologies Used
- Python
- OpenCV (cv2)
- NumPy
- Google Colab

## Requirements
Install the required libraries:

```bash
pip install opencv-python numpy
```

## How to Run
1. Download the project notebook.
2. Open Google Colab.
3. Upload the `Task_openCV.ipynb` file.
4. Upload the required input images.
5. Run all cells one by one.
6. View the generated image processing outputs.

## Input Images
- passport_image.jfif
- group photo.png

## Output
The project generates different image processing results, including passport photos, grayscale images, edited profile pictures, watermarked images, drawings, and greeting cards.
